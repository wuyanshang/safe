# 银行保险机构数据安全管理办法（2025年）- 数据分类分级要求

## 概述

国家金融监督管理总局发布《银行保险机构数据安全管理办法》，自2025年1月1日起施行。
共八十一条，包含总则、数据安全治理、数据分类分级、数据安全管理、数据安全技术保护、个人信息保护、数据安全风险监测与处置、监督管理及附则九个章节。

## 数据分类分级体系

银行保险机构应当按照"谁管业务、谁管业务数据、谁管数据安全"的原则，将数据分为以下四类：

### 1. 核心数据
- 关系国家安全、金融市场稳定的数据
- 一旦被篡改、破坏、泄露或者非法获取、非法利用，可能直接危害国家安全
- 由金融监管总局制定银行业保险业重要数据目录
- 对应JR/T 0197中的5级数据

### 2. 重要数据
- 一旦遭到篡改、破坏、泄露或者非法获取、非法利用，可能危害国家安全、公共利益
- 银行保险机构应向金融监管总局或其派出机构报送重要数据目录
- 对应JR/T 0197中的5级数据

### 3. 敏感数据
- 涉及个人隐私、商业秘密等，一旦泄露可能对个人、企业权益造成损害
- 包括个人金融信息中的C3、C2类别
- 对应JR/T 0197中的4级、3级数据

### 4. 一般数据
- 不属于上述三类的其他数据
- 对应JR/T 0197中的2级、1级数据

## 分类分级制度要求

- 建立数据目录和分类分级规范
- 动态维护数据分类分级结果
- 发生重大变化时更新报备重要数据目录
- 定期开展数据安全风险评估（每年至少一次）

## 个人信息保护专门规定

- 处理个人信息应当遵循合法、正当、必要和诚信原则
- 处理敏感个人信息应当取得个人的单独同意
- 不得过度收集个人信息
- 应当建立个人信息保护影响评估制度

## 与其他标准的关系

| 银保数安办法分类 | JR/T 0197级别 | JR/T 0171类别 | 个保法分类 |
|----------------|-------------|-------------|----------|
| 核心数据 | 5级 | - | - |
| 重要数据 | 5级 | - | - |
| 敏感数据 | 4级 | C3 | 敏感个人信息 |
| 敏感数据 | 3级 | C2 | 敏感个人信息 |
| 一般数据 | 2级 | C1 | 一般个人信息 |
| 一般数据 | 1级 | - | 公开信息 |
